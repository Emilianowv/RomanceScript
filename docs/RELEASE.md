# RomanceScript 8.1.1

- [Descargar Linux (.deb)](https://github.com/Emilianowv/RomanceScript/releases/download/v8.1.1/romancescript_8.1.1_all.deb)
- [Télécharger Windows x64 (.exe)](https://github.com/Emilianowv/RomanceScript/releases/download/v8.1.1/RomanceScript-8.1.1-Windows-x64.exe)

En Windows, ejecuta el instalador y añade RomanceScript en las opciones de teclado. [Guía Windows](https://github.com/Emilianowv/RomanceScript/blob/main/windows/README.md).

La tastiera conserva el mapa de 8.1.0. Grave seguido de espacio escribe el apóstrofo de `cos'è`. En Linux, ejecuta `romancescript user-install` después de actualizar el paquete y vuelve a iniciar sesión.
