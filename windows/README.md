# RomanceScript para Windows

Descarga el ZIP y extráelo. Contiene el diseño `RomanceScript.klc` y estas instrucciones. [Descargar el ZIP para Windows](https://github.com/Emilianowv/RomanceScript/releases/download/v8.1.0/RomanceScript-8.1.0-Windows.zip).

Abre `RomanceScript.klc` en Microsoft Keyboard Layout Creator, valida la distribución y genera el paquete mediante **Project → Build DLL and Setup Package**. [Microsoft Keyboard Layout Creator](https://www.microsoft.com/en-us/download/details.aspx?id=102134).

El archivo KLC se ha comprobado estáticamente. La compilación, instalación y escritura en Windows están pendientes de prueba. Consulta las posiciones y secuencias en la [guía de teclas](https://github.com/Emilianowv/RomanceScript/blob/v8.1.0/docs/TECLAS.md).
