# RomanceScript 8.1.1

- [Linux (.deb)](https://github.com/Emilianowv/RomanceScript/releases/download/v8.1.1/romancescript_8.1.1_all.deb)
- [Windows x64 (.exe)](https://github.com/Emilianowv/RomanceScript/releases/download/v8.1.1/RomanceScript-8.1.1-Windows-x64.exe)

En Windows, ejecuta el instalador y añade RomanceScript en las opciones de teclado. [Guía de Windows](https://github.com/Emilianowv/RomanceScript/blob/v8.1.1/windows/README.md).

Se mantiene la distribución de la 8.1.0, incluido grave seguido de Espacio para el apóstrofo. En Linux, ejecuta `romancescript user-install` tras actualizar el paquete y vuelve a iniciar sesión.
