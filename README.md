## Català

RomanceScript és un teclat QWERTY per escriure en sis llengües romàniques. També inclou ß i ẞ.

> La col·laboració va començar a la plaça.

**Linux.** Instal·la el paquet `.deb` i executa les dues ordres Linux de més avall. Tanca la sessió i torna a iniciar-la.

**Windows.** Executa el fitxer `.exe`, afegeix RomanceScript a les opcions de teclat i selecciona'l amb **Windows+espai**.

## Română

RomanceScript este o tastatură QWERTY pentru scrierea în șase limbi romanice. Include și caracterele ß și ẞ.

> Ștefan își cumpără pâine și înghețată.

**Linux.** Instalează pachetul `.deb` și rulează cele două comenzi Linux de mai jos. Deconectează-te, apoi conectează-te din nou.

**Windows.** Rulează fișierul `.exe`, adaugă RomanceScript în opțiunile tastaturii și selectează-l cu **Windows+spațiu**.
